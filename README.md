# FunVilla Play Zone

A vibrant and interactive website for a children's play zone and amusement park. FunVilla Play Zone offers a fun-filled experience for families with various rides, games, and activities.

## Features

- **Interactive Ride Section**: Browse and filter rides by category
- **Online Booking System**: Book tickets in advance with a user-friendly interface
- **Online Games**: Play fun games directly on the website
- **Responsive Design**: Optimized for all devices from mobile to desktop

## Pages

- **Home**: Introduction to FunVilla with featured attractions
- **Rides**: Detailed information about all rides with filtering options
- **Booking**: Online ticket reservation system
- **Games**: Interactive online games
- **Safety Information**: Guidelines for a safe visit
- **Location & Contact**: Find us and get in touch

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design
